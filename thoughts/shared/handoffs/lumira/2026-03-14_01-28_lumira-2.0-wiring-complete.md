## Learnings

1. **InnerDialogue parameters**: Takes voices (Dreamer, Critic, Curator, Rememberer) and mood_system, not memory_system directly. The Rememberer is where you pass graph_memory and enhanced_memory.

2. **Time ritual mood bias**: The scheduler's TIME_RITUALS has mood_bias arrays:
   - morning: energized, playful
   - afternoon: rebellious, chaotic
   - evening: serene, melancholic
   - night: introspective, contemplative

   Tests must use moods NOT in these lists to avoid triggering time rituals.

3. **Critic reuse**: The existing ArtistCritic from `personality/critic.py` works with InnerDialogue - no need for a separate Critic class.

## Post-Mortem

### What Worked
- Modular initialization via `_initialize_enhancements()` keeps main init clean
- Reusing existing ArtistCritic for dialogue critique
- Passing Rememberer with graph/enhanced memory for memory access in dialogue

### What Failed
- Initially passed wrong kwargs to InnerDialogue (memory_system, graph_memory instead of voices)
- Tried to import non-existent Critic class from inner_voices.py

### Key Decisions
- **Decision**: Create Rememberer with memory access, pass to InnerDialogue
  - Alternatives: Modify InnerDialogue to accept memories directly
  - Reason: Cleaner architecture - Rememberer is the memory voice

- **Decision**: Use existing ArtistCritic for dialogue
  - Alternatives: Create new Critic voice class
  - Reason: Avoid duplication, ArtistCritic already has critique logic
